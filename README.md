# 한걸음의 진심 — Firebase Spark 전용 수정본

## 현재 구현
- 익명 작성: 이용자가 처음 사진 또는 문의를 제출할 때 Firebase 익명 계정을 생성합니다. 단순 방문에는 계정을 만들지 않습니다.
- 관리자: 별도의 메모리 내 이메일 로그인 세션을 사용합니다. 관리자 로그아웃 시 원래 익명 이용자 세션을 유지합니다. 새로고침 시 관리자 세션은 종료됩니다.
- 사진: 최대 960px, 102399바이트(100KiB 미만)로 브라우저에서 압축합니다. WebP, 미지원 시 JPEG를 사용합니다. 목표 용량에 들어오지 않으면 업로드를 거절합니다. 원본은 저장하지 않습니다.
- 입력: JPG/PNG/WEBP 20MB 이하. 투명 영역은 흰색으로 변환하고 애니메이션은 정지 이미지가 됩니다.
- 저장: 이미지 바이트를 base64 문자열로 바꿔 Realtime Database에 저장합니다. 문자열 변환으로 약 33% 커집니다.
- 용량 제한: 규칙에서 이미지 문자열 최대 136532자를 제한합니다. 클라이언트 압축을 우회해도 저장되는 사진 문자열 크기는 제한됩니다. 실제 이미지 해상도는 브라우저 압축에서 제한하며 규칙은 픽셀을 해석하지 않습니다.
- 사진 수: p00~p99의 100개 슬롯만 허용합니다. UI만이 아니라 DB 규칙도 신규 임의 슬롯과 기존 사진 덮어쓰기를 거절합니다.
- 업로드: 목록과 이미지의 다중 경로 쓰기를 한 번에 수행합니다. 경쟁으로 같은 슬롯을 쓰면 실패한 쪽은 다른 빈 슬롯으로 재시도합니다.
- 갤러리: 메타데이터를 생성일 순으로 12개씩 조회한 뒤 해당 이미지 12장만 읽습니다. 관리자 목록은 제목만 읽고 사진 확인 버튼을 누를 때 이미지를 읽습니다.
- 삭제: 관리자만 이미지와 메타데이터를 원자적으로 삭제합니다. 삭제 확인 토큰으로 오래된 화면에서 재사용된 슬롯의 다른 사진을 지우는 것도 차단합니다. 이미 다른 방문자의 화면이나 기기에 내려받은 복사본은 회수할 수 없습니다.
- 문의: 기본 공개, 작성 시 비공개 선택 가능. 공개 문의는 비로그인 열람 가능, 비공개는 작성자 및 관리자만 열람 가능합니다. 제목도 비공개입니다. 관리자만 답변합니다.
- 익명 문의: 작성한 브라우저의 Firebase 익명 세션을 보존해야 합니다. 브라우저 데이터 삭제, 시크릿 창 종료, 다른 기기/도메인 접속 시 본인 문의를 다시 읽지 못할 수 있습니다. 운영 주소는 Vercel 대표 도메인으로 통일하세요.
- 갱신: 새 글/답변은 새로고침으로 확인합니다. 지속 실시간 구독은 사용하지 않습니다.

## 설정
먼저 「다음 할 일.md」를 확인하세요.
site-config.js의 databaseURL은 사용자 제공 주소로 입력했습니다.
https://home2-87a22-default-rtdb.firebaseio.com/
현재 다른 웹 앱 구성값은 비어 있으며 enabled: false이므로 연습 모드입니다.
연결 설정 오류 시 실제 운영 등록 버튼을 비활성화합니다. 운영 오류를 연습 저장 성공으로 처리하지 않습니다.

firebase.json에는 database.rules.json만 지정합니다.
Firebase Storage, Firestore, Cloudinary는 사용하지 않습니다.
Firebase CLI로 규칙을 배포한다면 프로젝트를 선택한 뒤:

    firebase deploy --only database

관리자는 신뢰할 수 있는 서버 환경에서 Firebase Admin SDK로 부여합니다:

    await getAuth().setCustomUserClaims('관리자_UID', { admin: true });

이 코드는 홈페이지 브라우저 코드에 넣지 마세요. 관리자 로그인 후에도 권한이 없으면 로그아웃 후 다시 로그인하세요.

## 저장 구조
- galleryMeta/p00~p99: uid, title, createdAt, uploadId
- galleryImages/p00~p99: uid, uploadId, mime, base64
- galleryDeleteTokens/p00~p99: 관리자 삭제 시 사용하는 마지막 uploadId (최대 100개 작은 문자열)
- questions/{자동ID}: uid, title, body, visibility, createdAt, answer, answeredAt

기존 사진이나 문의를 자동 이관하지 않습니다. 예전 photos 경로는 현 규칙에서 접근을 허용하지 않습니다. Firestore·Storage의 기존 파일을 삭제하거나 변경하지 않습니다.
visibility가 없는 옛 문의는 공개하지 않습니다. 해당 문의에 답변하려면 운영자가 원본을 확인한 뒤 Firebase 콘솔에서 visibility를 private로 지정하세요.

## 무료 한도
사진 100장 제한은 무료 사용량 절약을 위한 앱 제한입니다. 월간 트래픽 전체를 보장하는 무료 한도 계산기는 아닙니다.
사진 조회와 문의 다운로드도 Realtime Database 다운로드 사용량에 포함됩니다. Spark 플랜 한도 초과 시 서비스가 제한될 수 있습니다. Firebase 콘솔 사용량을 확인하세요.
https://firebase.google.com/docs/database/usage/billing
